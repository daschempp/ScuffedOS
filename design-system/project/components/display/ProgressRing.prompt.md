Circular progress ring — the nutrition tracker's signature widget.

```jsx
<ProgressRing value={1840} max={2100} size={84} color="green" label="88%" sublabel="kcal" />
```

`size` (px) and `thickness` (px) control geometry; `color` sets the ring; `trackColor` the unfilled arc. Center `label`/`sublabel` auto-scale to the diameter.
